# Site music

Drop `.mp3` files here (`.m4a`, `.ogg` and `.wav` work too). They're picked up
automatically when the site builds; there's no list to keep up to date.

- Name files `Artist - Title.mp3` and the player shows the artist and title.
- The song set as `defaultSong` in `src/data/portfolio.js` plays first; after
  that, "next" shuffles through the rest without repeats.
- Keep files reasonably small (a few MB each); visitors download whichever
  song is playing.
